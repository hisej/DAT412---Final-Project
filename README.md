## Project Overview

This project uses supervised machine learning techniques to predict whether a customer will subscribe to a service based on demographic and behavioral shopping features. The analysis compares three classification models: Logistic Regression, Random Forest, and XGBoost.

The Random Forest model achieved the highest performance, with a cross-validated accuracy of **84.4%**.
